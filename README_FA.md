# ربات خوشامدگوی کارتن‌یار

این ربات برای گروه‌های تلگرام ساخته شده و برای هر گروه می‌تواند متن خوشامدگویی جداگانه داشته باشد.

## نصب

Python 3.10 یا بالاتر نصب باشد، سپس:

```bash
pip install -r requirements.txt
```

توکن BotFather را به عنوان متغیر محیطی `BOT_TOKEN` تنظیم کنید.

### Windows PowerShell
```powershell
$env:BOT_TOKEN="توکن_ربات_شما"
python bot.py
```

### Linux / VPS
```bash
export BOT_TOKEN="توکن_ربات_شما"
python3 bot.py
```

## تنظیم متن در گروه

در گروه، یک مدیر می‌تواند بنویسد:

```text
/setwelcome 👋 سلام {mention} عزیز، به گروه «{group}» خوش آمدی!
```

متغیرهای قابل استفاده:
- `{mention}` = منشن عضو جدید
- `{name}` = نام عضو
- `{username}` = نام کاربری
- `{group}` = نام گروه

نمایش متن فعلی:
```text
/welcome
```

برگشت به متن پیش‌فرض:
```text
/resetwelcome
```

## نکته امنیتی
توکن ربات را داخل گروه یا برای افراد دیگر ارسال نکنید. بهتر است فقط به صورت متغیر محیطی نگهداری شود.

## وضعیت فعلی
ربات از Polling استفاده می‌کند و نیازی به دامنه یا SSL ندارد. کافی است برنامه روی یک کامپیوتر یا VPS روشن بماند.
